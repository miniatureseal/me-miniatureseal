03. Some Things I've Built

Thesis and Resulting Publication · 2025/2026

Is This Chart Lying to Me?

Automated detection of misleading data visualizations. My master's thesis research in collaboration with KU Leuven (Belgium) and TU Darmstadt. Helped derive the annotation schema for the real-world misleading visualization dataset Misviz, which includes 2,604 real-world misleading charts, and built a data generation pipeline to create a synthetic dataset Misviz-synth with 57,665 synthetic misleading data visualizations. Fine-tuned classifiers and generative vision-language models for chart-deception detection. Accepted at ACL 2026, San Diego. Created in equal contribution with my supervisor, Jonathan Tonglet.

University Project · 2024

Smart Reply Generation via RAG

RAG-based message retrieval system for generating contextually enriched smart replies in a job matching application, using context from previous chats. Similarity matching is done via cosine similarity of vector representations — no custom model trained. A seminar study with participants assuming job-matching personas found high conversational relevance, perceived naturalness, and strong likelihood of adoption.

  • RAG

Bachelor-Thesis at Fresenius SE · 2019

Network Intrusion Defense System

Bachelor's thesis at Fresenius SE: selection, development, and testing of an automated reactive defense system against internal network attacks within a global enterprise network. Evaluated end-to-end against the WannaCry ransomware case study, demonstrating automated containment and incident-response capabilities. As-Is and To-Be state and process documented via BPMN. Aligned with BSI and NIST frameworks. Graded 1.4 (German scale equivalent to an A).
